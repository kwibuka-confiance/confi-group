# Git Workflow

## Branches

- `main` — production-ready
- `develop` — integration branch
- `feature/*`
- `fix/*`
- `docs/*`
- `release/*`

## Commits

Use conventional commits.

Examples:

- `docs: add multi-tenant architecture`
- `feat: implement stock receiving`
- `fix: prevent negative inventory`
- `test: add sale completion integration tests`

## Pull Requests

Every PR must include:

- Summary
- Requirement IDs
- Screenshots where relevant
- Test evidence
- Security impact
- Localization impact
- Database impact
