# Security Architecture

## Principles

- Secure by default
- Least privilege
- Defense in depth
- Tenant isolation
- Full traceability
- No secrets in source control

## Controls

- Strong authentication
- MFA support
- Permission checks
- Tenant resolution
- Rate limiting
- Secure headers
- Input validation
- Output encoding
- Audit logs
- Session revocation
- Encryption in transit
- Encryption at rest where supported
- Secret management

## Sensitive Operations

Use:

- Confirmation
- Reason
- Reauthentication
- Approval
- Idempotency
- Audit

## Development Security

- Dependency scanning
- Secret scanning
- Static analysis
- Container scanning
- Security-focused code review
- Regular penetration testing
